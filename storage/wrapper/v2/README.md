# wrapper v2 storage

This directory is the runtime home of the wrapper bakery v2:

- `bin/<engine>/<os>-<arch>/v<version>/<engine>` — published per-platform binaries.
- `cache/<host_id>/<engine>/<config_version>/{config.json,config.json.sig,meta.json}` — pre-baked configs.
- `keys/signing.ed25519` — server private key (chmod 600, generated by `scripts/wrapper-v2-init-keys.sh`).
- `keys/signing.ed25519.pub` — public counterpart embedded into the Go binaries at build time.

Cache entries are owned by `App\Services\Wrapper\V2\BakeCache`. The cache is
filesystem-only; the database holds the per-host pointer (`hosts.config_version`).
