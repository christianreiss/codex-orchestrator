Insecure Host Window

Duration granted when enabling insecure hosts.

Applies to the next enable and persists locally.

10 min

Each `/auth` extends by this duration (0–8 hours, log scale). Trailing grace allows final auth/usage push after expiry.

Insecure Host Approval

Require admin confirmation when windows are closed.

When enabled, cdx waits for approval if a websocket admin is connected.

Cron Auto-Update

Fleet-wide Codex binary auto-update via cron.

When enabled, hosts with cdx --cron installed will automatically update the Codex binary once daily (0–4 AM, randomized per host). Per-host overrides available in host details. Default: off.

Host Pruning

Delete inactive hosts after N days (0 disables pruning).

Applies to inactive hosts only; unprovisioned hosts still prune after 30 minutes.

30 days

Honoured during auth/register/admin host listings.
