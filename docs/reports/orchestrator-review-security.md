## Zod wire compatibility

All 15 Workflow schemas compare equal after generation. Of 117 generated Chatty tool schemas, 113 compare equal. Three digest arguments now advertise their already-enforced length of 64 and one quota enum lists its three members in a different order. Legacy GUIDs, minute-precision UTC stamps, optional seconds, compact offsets, optional connector category grants and default-denied connector ceilings have explicit regression coverage. Typed integers use the JavaScript safe range; inputs beyond it could already lose precision in JavaScript or refer to the wrong identity. No valid MySQL integer ID in an existing 32-bit PK column falls outside this range.

For a constrained array of eight benign test values with a maximum length of four, v3 performed eight element validations and created nine issues. The fixed parser performs zero element validations and returns the size error. The initial wizard and public OAuth registration additionally collapse repeated members of their finite engine, grant-type and response-type lists. A malformed large list reaches field validation with at most the enum cardinality plus one invalid item. In a fresh MySQL-backed built API, a Chromium owner session submitted 33 invalid secret tags against the 32-tag contract. It received HTTP 400, `invalid_request` and `param=tags`. A valid request in the same session persisted a new synthetic secret which a following GET returned.

## Measurements and limits

With an identical fixture of 200 completed run directories, Linux strace counted 1,202 filesystem operations under the run root in 12.007 seconds on the original worker and 2 in 12.000 seconds on the revised worker. The detector remained inactive in both samples. This measures root-path filesystem activity. It does not measure SQL, CPU or behavior under scanner load. The independent owner-observation matrix and its release implications belong to the parent report.

Targeted verification used `npm ci`, API typecheck/lint/build, the SPA/passkey/SMTP tests, and real MySQL tests for Slop import and lifetime. The worker suites cover a report already present at startup and report arrival with all filesystem events dropped. The isolated DB test covers retained active runs, expiry after completion, the touch cutoff, and deletion of lost-project jobs. Provider logins, Internet SMTP delivery and externally issued passkeys were outside these fixture boundaries.

On the final build, the combined navigation, public validation, connector and authorization selection passed 91 tests. A separate DB-enabled OAuth and setup run passed all 20 tests, including a real token exchange and owner hydration. API lint returned zero errors with 226 warnings. The dedicated auth fixture returned HTTP 200 at `/healthz`, HTTP 401 JSON `admin_required` on `/admin/hosts/`, and HTTP 503 on `/readyz` with the missing runner, signing and wrapper prerequisites identified. The final Runner suite passed 284 tests with two skips.

## TE-003 – Instance CLI fixture write isolation

The local API dependency mirror linked its `bin` and `scripts` directories to the integration worktree. Node’s default recursive copy preserved those links in a temporary CLI checkout. The install and deploy doubles consequently replaced the worktree scripts. The corresponding Git operations then failed with “beyond a symbolic link”. The original user checkout stayed clean. The integration scripts were reconstructed from integrated commit `861b9d42a`, retaining its cutover changes, plus the two SEC-002 runtime-directory additions.

A regression using a symlinked source first resolved a writable fixture path into the worktree and failed the containment assertion. With source symlinks dereferenced during copy, the test verified seven private paths and modified their contents while the source bytes stayed unchanged. The Instance CLI, worker-volume and detached-deployment suites passed 29 tests with the opt-in Docker smoke skipped. The 15 owner-cutover and wrapper-deployment contract tests also passed. Independent SHA-256 comparisons after the run matched all seven source files. Both production scripts passed Bash syntax checks. Other test-mutated paths under `bin` and `scripts` matched Git, and the Compose diff only contained SEC-002.

## AC-005 integration regression check

Four of the seven MySQL attachment-recovery cases failed identically in the combined coverage run and on a freshly migrated, automatically discarded private schema. The integration diff against `861b9d42a` had removed the provider's wait for attachment persistence and reauthorization, cleanup on rejection and completion wait on detach. The product integration restored those paths. The unchanged seven tests then passed on another private schema, including rejection and owner fencing on a failed durable write. A private V8 coverage run also passed 7/7. That one-file run exited 1 at the unchanged repository-wide coverage thresholds. The canonical all-suite coverage result belongs to the main report.
