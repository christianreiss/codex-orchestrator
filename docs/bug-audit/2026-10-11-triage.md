## Resolution evidence

### transfers

F005, F022, F065, F066, F121, F122, F123. Append under row lock; fsync before committed offset; truncate uncommitted tails before retry.

### memory-cas

F006, F073, F074, F075. Serialize expected-digest validation and replacement with one slug lock; preserve conflicts.

### git-director

F011, F108, F109, F110, F111, F112, F113, F114, F115. Bind authoritative engine/caller identity; retain live registrations and leases using fresh presence; refresh polling before expiry.

### native-signals

F001, F037, F047, F051, F052, F053, F054, F055, F062, F068, F069, F070, F078, F087, F089, F091, F094, F105, F127. Forward INT/TERM/HUP, preserve 128+signal and stop reasons; bounded native process/group cleanup and inherited session fences.

### grok-runtime-cleanup

F002, F057, F058, F092, F101, F104, F128, F142. Protect and reclaim owned private runtime/login directories across wrapper death; preserve live native users.

### grok-login-auth

F003, F031, F050, F071. Use device-auth login; separate metadata observation from credential-grant refresh and allocation.

### remote-stub

F004. Mark unavailable command surface consistently in served guidance, CLI help, settings and docs; keep explicit E_NOT_IMPLEMENTED.

### engine-assignment

F007, F021. Filter configured defaults through enabled fleet engines; preserve existing host assignment.

### agents-lock

F008, F076. Reject cross-engine document locks and ignore invalid legacy locks when selecting served content.

### gateway-protocol

F009, F063, F064, F103. Validate stream type consistently (null remains omission-compatible); preserve unknown finish reason as null.

### codex-atomic-sync

F010, F027. Unique temporary files plus fsync/rename prevent concurrent truncated AGENTS/config publication.

### daemon-stdin

F012, F035, F126. Close prompt-backed Grok stdin instead of submitting the task twice.

### host-pruning

F013, F129, F131, F135, F136, F141. Enforce temporary expiry, authenticated renewal and abandoned/inactive cleanup with locked rechecks and three-engine provisioning.

### installer-tokens

F014, F132, F133, F134, F138, F139, F140. Build before consume; validate before atomic replacement; revoke on key/assignment/deletion changes. Delivered installers remain single use.

### grok-maintenance

F015, F016, F028, F061, F072, F079, F086, F093. Honor maintenance flags, live-home locks, pinning, suspension and trust-loss cleanup across installed Grok state.

### codex-suspension

### quota-server

F018, F106. Retain last measured quota plus truthful age/error metadata; cancel and drain the usage worker before database shutdown.

### project-claims

F019, F042, F116, F117, F118, F119, F120. Use fresh presence to project and reclaim dead claims; concise targeted CoCo reads replace mandatory full bootstrap.

### browseros-config

F020. Inject local BrowserOS independently of fleet MCP/bearer availability.

### gateway-cancellation

F023, F030, F077, F081, F082, F083, F084, F096, F097. Propagate disconnect/shutdown and deadlines through all route/backend pairs, runner body reads and native process-group cleanup.

### reboot-receiver

F024, F025, F049, F088. Restore original receipts in headless continuations without false automatic readiness; install lifecycle hooks independently of reception.

### worker-processes

F026, F038, F046. Stop native descendants along with detached worker wrappers using bounded process-group supervision.

### cron-cancellation

F029. Use the signal-cancelled context through trailing maintenance reconciliation.

### failed-turn-renewal

F032. Fresh failed/interrupted native turns stop claim renewal even without watchdog; preserve explicit result receipts and ambiguous outcome.

### claude-fallback

F033, F100. Keep manual MCP tools while disabling automatic receiver admission/readiness in explicit fallback.

### claude-installer

### grok-missing-transcript

### ip-rebind

### grok-leader-activity

### skill-crash-safety

### receiver-questions

Final integration check results are recorded here before delivery. Focused evidence includes real disposable-MySQL transaction races, actual Unix socket/HTTP disconnects, bounded native subprocess trees, and SIGKILL-only test fixtures. No production service, provider login, live agent, or native user transcript was used as a destructive fixture.

- `F034` and `F124` are intentional runtime behavior; their documentation drift is corrected.
