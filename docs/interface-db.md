# Database Interface (Source of Truth)

Schema DDL is defined in `Database::migrate()` (MySQL only). Operationally, schema/backfill runs should happen via `scripts/migrate.php` before traffic; request-path migration can be toggled with `RUN_MIGRATIONS_ON_BOOT`/`RUN_BACKFILLS_ON_BOOT`. Column names and types below are derived from `src/Database.php` and subsequent `ensureColumnExists`/index helpers.

- **hosts** — `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `fqdn` VARCHAR(255) UNIQUE, `api_key` CHAR(64) UNIQUE (sha256 hash of the host API key), `api_key_hash` CHAR(64) NULL, `api_key_enc` LONGTEXT NULL (secretbox-encrypted plaintext API key for baking wrappers), `status` VARCHAR(32) NOT NULL DEFAULT `active`, `secure` TINYINT(1) NOT NULL DEFAULT `1`, `allow_roaming_ips` TINYINT(1) NOT NULL DEFAULT `0`, `reverse_dns_mode` TINYINT(1) NULL (NULL = global, `1` enabled, `0` disabled), `last_refresh` VARCHAR(100) NULL, `auth_digest` VARCHAR(128) NULL, `ip4` VARCHAR(64) NULL, `ip6` VARCHAR(64) NULL, `client_version` VARCHAR(64) NULL, `client_version_override` VARCHAR(64) NULL, `agents_document_id_override` BIGINT UNSIGNED NULL, `wrapper_version` VARCHAR(64) NULL, `api_calls` BIGINT UNSIGNED NOT NULL DEFAULT `0`, `insecure_enabled_until` DATETIME NULL, `insecure_grace_until` DATETIME NULL, `insecure_window_minutes` INT NULL, `force_ipv4` TINYINT(1) NOT NULL DEFAULT `0`, `curl_insecure` TINYINT(1) NOT NULL DEFAULT `0`, `expires_at` VARCHAR(100) NULL, `vip` TINYINT(1) NOT NULL DEFAULT `0`, `lane_preference` VARCHAR(16) NULL (`normal`/`spark` host lane steering override), `model_override` VARCHAR(128) NULL, `reasoning_effort_override` VARCHAR(32) NULL, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL; indexes: `idx_hosts_updated_at` on (`updated_at`), `idx_hosts_expires_at` on (`expires_at`).
- **auth_payloads** — canonical auth snapshots (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `last_refresh` VARCHAR(100) NOT NULL, `sha256` CHAR(64) NOT NULL, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `body` LONGTEXT NULL canonical `auth.json`, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_auth_payloads_last_refresh` on (`last_refresh`), `idx_auth_payloads_created_at` on (`created_at`). `body` is stored as libsodium `secretbox` ciphertext (`sbox:v1:{base64}` legacy or `sbox:v1:kid=<id>:{base64}` in keyring mode).
- **auth_entries** — per-target tokens for each payload (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `payload_id` BIGINT UNSIGNED NOT NULL FK → `auth_payloads.id`, `target` VARCHAR(255) NOT NULL, `token` TEXT NOT NULL, `token_type` VARCHAR(32) DEFAULT `bearer`, `organization` VARCHAR(255) NULL, `project` VARCHAR(255) NULL, `api_base` VARCHAR(255) NULL, `meta` JSON NULL, `created_at` VARCHAR(100) NOT NULL); index: `idx_entries_payload` on (`payload_id`); unique key `uniq_entry_target` on (`payload_id`, `target`). `token` uses the same `sbox:v1`/`kid` format as payload bodies.
- **slash_commands** — server-side slash command prompts (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `filename` VARCHAR(255) UNIQUE, `sha256` CHAR(64) NOT NULL, `description` TEXT NULL, `argument_hint` VARCHAR(255) NULL, `prompt` LONGTEXT NOT NULL, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL, `deleted_at` VARCHAR(100) NULL); index: `idx_slash_commands_updated_at` on (`updated_at`).
- **skills** — canonical Skill manifests (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `slug` VARCHAR(255) UNIQUE, `sha256` CHAR(64) NOT NULL, `display_name` VARCHAR(255) NULL, `description` TEXT NULL, `manifest` LONGTEXT NOT NULL, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL, `deleted_at` VARCHAR(100) NULL); index: `idx_skills_updated_at` on (`updated_at`).
- **coord_projects** — shared project registry (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `slug` VARCHAR(255) NOT NULL UNIQUE, `about_json` JSON NULL, `roster_markdown` LONGTEXT NULL, `latest_event_seq` BIGINT UNSIGNED NOT NULL DEFAULT `0`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL, `archived_at` VARCHAR(100) NULL); indexes: `idx_coord_projects_updated_at` on (`updated_at`), `idx_coord_projects_archived_at` on (`archived_at`).
- **coord_project_notes** — shared project notes (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `project_id` BIGINT UNSIGNED NOT NULL FK → `coord_projects.id`, `header` VARCHAR(255) NOT NULL, `body` LONGTEXT NOT NULL, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); indexes: `idx_coord_project_notes_project` on (`project_id`), `idx_coord_project_notes_updated_at` on (`updated_at`).
- **coord_project_todos** — shared project todo items (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `project_id` BIGINT UNSIGNED NOT NULL FK → `coord_projects.id`, `title` VARCHAR(255) NOT NULL, `detail` LONGTEXT NOT NULL, `done` TINYINT(1) NOT NULL DEFAULT `0`, `done_at` VARCHAR(100) NULL, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); indexes: `idx_coord_project_todos_project` on (`project_id`), `idx_coord_project_todos_updated_at` on (`updated_at`), `idx_coord_project_todos_done` on (`done`).
- **coord_project_files** — shared project artifacts (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `project_id` BIGINT UNSIGNED NOT NULL FK → `coord_projects.id`, `stored_name` VARCHAR(255) NOT NULL, `description` TEXT NULL, `content` LONGTEXT NOT NULL, `content_sha256` CHAR(64) NOT NULL, `mime_type` VARCHAR(255) NULL, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); unique key `uniq_coord_project_file_name` on (`project_id`, `stored_name`); indexes: `idx_coord_project_files_project` on (`project_id`), `idx_coord_project_files_updated_at` on (`updated_at`).
- **coord_project_feedback** — project feedback inbox (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `project_id` BIGINT UNSIGNED NOT NULL FK → `coord_projects.id`, `type` VARCHAR(32) NOT NULL, `title` VARCHAR(255) NOT NULL, `body` LONGTEXT NOT NULL, `status` VARCHAR(32) NOT NULL DEFAULT `open`, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); indexes: `idx_coord_project_feedback_project` on (`project_id`), `idx_coord_project_feedback_updated_at` on (`updated_at`).
- **coord_project_events** — append-only project activity log (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `project_id` BIGINT UNSIGNED NOT NULL FK → `coord_projects.id`, `seq` BIGINT UNSIGNED NOT NULL, `event_type` VARCHAR(64) NOT NULL, `action` VARCHAR(64) NOT NULL, `entity_type` VARCHAR(64) NULL, `entity_id` VARCHAR(64) NULL, `payload_json` JSON NULL, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `created_at` VARCHAR(100) NOT NULL); unique key `uniq_coord_project_event_seq` on (`project_id`, `seq`); indexes: `idx_coord_project_events_project` on (`project_id`), `idx_coord_project_events_created_at` on (`created_at`).
- **agents_documents** — versioned AGENTS.md editions (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `sha256` CHAR(64) NOT NULL, `body` LONGTEXT NOT NULL, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); index: `idx_agents_documents_updated_at` on (`updated_at`).
- **agents_document_state** — serving mode for AGENTS.md (`id` TINYINT UNSIGNED PRIMARY KEY, `mode` VARCHAR(16) NOT NULL (`latest` or `locked`), `active_document_id` BIGINT UNSIGNED NULL FK → `agents_documents.id`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); index: `idx_agents_document_state_updated_at` on (`updated_at`).
- **client_config_documents** — canonical `config.toml` (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `sha256` CHAR(64) NOT NULL, `body` LONGTEXT NOT NULL, `settings` JSON NULL, `source_host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); index: `idx_client_config_documents_updated_at` on (`updated_at`).
- **mcp_memories** — MCP memory store scoped per host (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `host_id` BIGINT UNSIGNED NOT NULL FK → `hosts.id`, `memory_key` VARCHAR(128) NOT NULL, `content` LONGTEXT NOT NULL, `metadata` JSON NULL, `tags` JSON NULL, `tags_text` TEXT NULL, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL, `deleted_at` VARCHAR(100) NULL); unique key `uniq_memories_host_key` on (`host_id`, `memory_key`); indexes: `idx_memories_host` on (`host_id`), fulltext `idx_memories_search` on (`content`, `tags_text`). These rows are intentionally host-scoped. Keys matching `^coco(?:$|[._:-])` are reserved and rejected so CoCo shared handoffs cannot be mis-modeled here.
- **host_auth_states** — last canonical payload served per host (`host_id` BIGINT UNSIGNED NOT NULL PRIMARY KEY FK → `hosts.id`, `payload_id` BIGINT UNSIGNED NOT NULL FK → `auth_payloads.id`, `seen_digest` CHAR(64) NOT NULL, `seen_at` VARCHAR(100) NOT NULL).
- **logs** — audit events (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `action` VARCHAR(64) NOT NULL, `details` LONGTEXT NULL, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_logs_host` on (`host_id`), `idx_logs_created_at` on (`created_at`).
- **admin_events** — admin websocket event feed (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `type` VARCHAR(64) NOT NULL, `host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `payload` JSON NULL, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_admin_events_host` on (`host_id`), `idx_admin_events_type` on (`type`), `idx_admin_events_created_at` on (`created_at`).
- **admin_users** — admin dashboard users (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `name` VARCHAR(255) NOT NULL, `username` VARCHAR(64) NOT NULL UNIQUE, `email` VARCHAR(255) NOT NULL UNIQUE, `password_hash` VARCHAR(255) NOT NULL, `access_level` VARCHAR(32) NOT NULL, `active` TINYINT(1) NOT NULL DEFAULT `1`, `last_login_at` VARCHAR(100) NULL, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); indexes: `idx_admin_users_access` on (`access_level`), `idx_admin_users_active` on (`active`).
- **admin_sessions** — admin login sessions (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `user_id` BIGINT UNSIGNED NOT NULL FK → `admin_users.id`, `token_hash` CHAR(64) NOT NULL UNIQUE, `ip` VARCHAR(64) NULL, `user_agent` VARCHAR(255) NULL, `created_at` VARCHAR(100) NOT NULL, `last_seen_at` VARCHAR(100) NOT NULL, `expires_at` VARCHAR(100) NOT NULL); indexes: `idx_admin_sessions_user` on (`user_id`), `idx_admin_sessions_expires` on (`expires_at`).
- **admin_password_resets** — password recovery tokens (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `user_id` BIGINT UNSIGNED NOT NULL FK → `admin_users.id`, `token_hash` CHAR(64) NOT NULL UNIQUE, `expires_at` VARCHAR(100) NOT NULL, `used_at` VARCHAR(100) NULL, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_admin_password_resets_user` on (`user_id`), `idx_admin_password_resets_expires` on (`expires_at`).
- **insecure_auth_requests** — pending approvals for insecure hosts (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `host_id` BIGINT UNSIGNED NOT NULL FK → `hosts.id`, `status` VARCHAR(24) NOT NULL, `request_ip` VARCHAR(64) NULL, `requested_at` VARCHAR(100) NOT NULL, `resolved_at` VARCHAR(100) NULL, `updated_at` VARCHAR(100) NOT NULL); indexes: `idx_insecure_auth_requests_host` on (`host_id`), `idx_insecure_auth_requests_status` on (`status`), `idx_insecure_auth_requests_requested_at` on (`requested_at`).
- **insecure_domain_allows** — auto-allow rules for insecure-host approvals (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `domain` VARCHAR(255) NOT NULL UNIQUE, `window_minutes` INT NOT NULL, `enabled_until` VARCHAR(100) NULL, `revoked_at` VARCHAR(100) NULL, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); indexes: `idx_insecure_domain_allows_enabled_until` on (`enabled_until`), `idx_insecure_domain_allows_revoked_at` on (`revoked_at`).
- **mcp_access_logs** — MCP access audit events (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `client_ip` VARCHAR(64) NULL, `method` VARCHAR(64) NOT NULL, `name` VARCHAR(128) NULL, `success` TINYINT(1) NOT NULL DEFAULT `0`, `error_code` INT NULL, `error_message` TEXT NULL, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_mcp_logs_host` on (`host_id`), `idx_mcp_logs_method` on (`method`), `idx_mcp_logs_created_at` on (`created_at`).
- **mcp_session_tokens** — short-lived MCP bearer tokens for insecure-host managed config (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `token` CHAR(64) NOT NULL UNIQUE (sha256 hash), `token_enc` LONGTEXT NULL, `host_id` BIGINT UNSIGNED NOT NULL FK → `hosts.id`, `expires_at` VARCHAR(100) NOT NULL, `last_used_at` VARCHAR(100) NULL, `created_at` VARCHAR(100) NOT NULL, `updated_at` VARCHAR(100) NOT NULL); indexes: `idx_mcp_session_tokens_host` on (`host_id`), `idx_mcp_session_tokens_expires_at` on (`expires_at`).
- **ip_rate_limits** — per-IP buckets for request throttling (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `ip` VARCHAR(64) NOT NULL, `bucket` VARCHAR(64) NOT NULL, `count` INT UNSIGNED NOT NULL DEFAULT `0`, `reset_at` VARCHAR(100) NOT NULL, `last_hit` VARCHAR(100) NOT NULL, `created_at` VARCHAR(100) NOT NULL); unique key `uniq_ip_bucket` on (`ip`, `bucket`); index: `idx_rate_limits_reset_at` on (`reset_at`). Used for the `global` and `auth-fail` buckets.
- **install_tokens** — single-use installer tokens (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `token` CHAR(64) NOT NULL UNIQUE (sha256 hash), `token_enc` LONGTEXT NULL, `host_id` BIGINT UNSIGNED NOT NULL FK → `hosts.id`, `fqdn` VARCHAR(255) NOT NULL, `api_key` CHAR(64) NOT NULL (sha256 hash), `api_key_enc` LONGTEXT NULL, `base_url` VARCHAR(255) NULL, `expires_at` VARCHAR(100) NOT NULL, `used_at` VARCHAR(100) NULL, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_install_tokens_host` on (`host_id`), `idx_install_tokens_expires_at` on (`expires_at`).
- **auth_seed_tokens** — single-use auth seeding tokens (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `token` CHAR(64) NOT NULL UNIQUE (sha256 hash), `token_enc` LONGTEXT NULL, `base_url` VARCHAR(255) NULL, `expires_at` VARCHAR(100) NOT NULL, `used_at` VARCHAR(100) NULL, `created_at` VARCHAR(100) NOT NULL); index: `idx_auth_seed_tokens_expires_at` on (`expires_at`).
- **token_usage_ingests** — one row per `/usage` POST for audit (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `entries` INT UNSIGNED NOT NULL DEFAULT `0`, `total` BIGINT UNSIGNED NULL, `input_tokens` BIGINT UNSIGNED NULL, `output_tokens` BIGINT UNSIGNED NULL, `cached_tokens` BIGINT UNSIGNED NULL, `reasoning_tokens` BIGINT UNSIGNED NULL, `cost` DECIMAL(18,6) NULL, `client_ip` VARCHAR(64) NULL, `payload` LONGTEXT NULL, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_usage_ingests_host` on (`host_id`), `idx_usage_ingests_created_at` on (`created_at`).
- **token_usages** — per-host token usage rows from `/usage` (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `ingest_id` BIGINT UNSIGNED NULL FK → `token_usage_ingests.id`, `total` BIGINT UNSIGNED NULL, `input_tokens` BIGINT UNSIGNED NULL, `output_tokens` BIGINT UNSIGNED NULL, `cached_tokens` BIGINT UNSIGNED NULL, `reasoning_tokens` BIGINT UNSIGNED NULL, `cost` DECIMAL(18,6) NULL, `model` VARCHAR(128) NULL, `line` TEXT NULL, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_token_usage_host` on (`host_id`), `idx_token_usage_ingest` on (`ingest_id`), `idx_token_usage_created_at` on (`created_at`). `/usage` can submit multiple rows at once; admin aggregations surface these as `total`/`input`/`output`/`cached`/`reasoning` plus `cost`.
- **chatgpt_usage_snapshots** — account-level ChatGPT `/wham/usage` snapshots (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `host_id` BIGINT UNSIGNED NULL FK → `hosts.id`, `status` VARCHAR(16) NOT NULL, `plan_type` VARCHAR(64) NULL, `rate_allowed` TINYINT(1) NULL, `rate_limit_reached` TINYINT(1) NULL, `primary_used_percent` INT UNSIGNED NULL, `primary_limit_seconds` BIGINT UNSIGNED NULL, `primary_reset_after_seconds` BIGINT UNSIGNED NULL, `primary_reset_at` VARCHAR(100) NULL, `secondary_used_percent` INT UNSIGNED NULL, `secondary_limit_seconds` BIGINT UNSIGNED NULL, `secondary_reset_after_seconds` BIGINT UNSIGNED NULL, `secondary_reset_at` VARCHAR(100) NULL, `spark_limit_name` VARCHAR(128) NULL, `spark_metered_feature` VARCHAR(128) NULL, `spark_rate_allowed` TINYINT(1) NULL, `spark_rate_limit_reached` TINYINT(1) NULL, `spark_primary_used_percent` INT UNSIGNED NULL, `spark_primary_limit_seconds` BIGINT UNSIGNED NULL, `spark_primary_reset_after_seconds` BIGINT UNSIGNED NULL, `spark_primary_reset_at` VARCHAR(100) NULL, `spark_secondary_used_percent` INT UNSIGNED NULL, `spark_secondary_limit_seconds` BIGINT UNSIGNED NULL, `spark_secondary_reset_after_seconds` BIGINT UNSIGNED NULL, `spark_secondary_reset_at` VARCHAR(100) NULL, `has_credits` TINYINT(1) NULL, `unlimited` TINYINT(1) NULL, `credit_balance` VARCHAR(128) NULL, `approx_local_messages` TEXT NULL, `approx_cloud_messages` TEXT NULL, `raw` LONGTEXT NULL, `error` TEXT NULL, `fetched_at` VARCHAR(100) NOT NULL, `next_eligible_at` VARCHAR(100) NOT NULL, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_chatgpt_usage_host` on (`host_id`), `idx_chatgpt_usage_fetched` on (`fetched_at`).
- **pricing_snapshots** — model pricing (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `model` VARCHAR(128) NOT NULL, `currency` VARCHAR(8) NOT NULL DEFAULT `USD`, `input_price_per_1k` DECIMAL(12,6) NOT NULL DEFAULT `0`, `output_price_per_1k` DECIMAL(12,6) NOT NULL DEFAULT `0`, `cached_price_per_1k` DECIMAL(12,6) NOT NULL DEFAULT `0`, `source_url` TEXT NULL, `raw` LONGTEXT NULL, `fetched_at` VARCHAR(100) NOT NULL, `created_at` VARCHAR(100) NOT NULL); indexes: `idx_pricing_model` on (`model`), `idx_pricing_fetched` on (`fetched_at`).
- **host_auth_digests** — up to three recent digests per host (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `host_id` BIGINT UNSIGNED NOT NULL FK → `hosts.id`, `digest` VARCHAR(128) NOT NULL, `last_seen` VARCHAR(100) NOT NULL, `created_at` VARCHAR(100) NOT NULL); unique key `unique_host_digest` on (`host_id`, `digest`); index: `idx_auth_digest_host` on (`host_id`).
- **host_users** — usernames per host for uninstall cleanup (`id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, `host_id` BIGINT UNSIGNED NOT NULL FK → `hosts.id`, `username` VARCHAR(255) NOT NULL, `hostname` VARCHAR(255) NULL, `first_seen` VARCHAR(100) NOT NULL, `last_seen` VARCHAR(100) NOT NULL); unique key `uniq_host_user` on (`host_id`, `username`); index: `idx_host_users_host` on (`host_id`).
- **versions** — key/value version store (`name` VARCHAR(191) PRIMARY KEY, `version` VARCHAR(191) NOT NULL, `updated_at` VARCHAR(100) NOT NULL). Keys used in code include: `client_available` (cached client version from GitHub), `client_version_lock` (fleet Codex CLI pin), `wrapper` (wrapper version), `canonical_payload_id`, `runner_state`, `runner_last_ok`, `runner_last_fail`, `runner_last_check`, `runner_boot_id`, `daily_preflight`, `quota_hard_fail`, `quota_limit_percent`, `quota_week_partition`, `api_disabled`, `cdx_silent`, `reverse_dns_enabled`, `inactivity_window_days`, `insecure_approval_enabled`, `projects_module_enabled`, `admin_ws_connections`, `cdx_model`, `cdx_reasoning_effort`, and one-time migration markers `auth_secretbox_migration_v1`, `hosts_api_key_encryption_backfill_v1`, `token_usage_cost_backfill_v1`.

Encryption: `AUTH_ENCRYPTION_KEY` (single-key mode) is generated into `.env` on first boot if missing by `EncryptionKeyManager`. Optional keyring mode uses `AUTH_ENCRYPTION_KEYS` (`kid:base64,...`) plus `AUTH_ENCRYPTION_ACTIVE_KID`; new writes then include `kid` in the ciphertext prefix while legacy `sbox:v1:{base64}` remains decryptable. `api_key_enc`, `auth_payloads.body`, `auth_entries.token`, `install_tokens.token_enc`, `install_tokens.api_key_enc`, and `auth_seed_tokens.token_enc` are stored as secretbox ciphertexts via `SecretBox`. One-time startup backfills are gated by `versions` keys: `auth_secretbox_migration_v1` (`auth_payloads.body`, `auth_entries.token`, `install_tokens.token_enc`/`api_key_enc`) and `hosts_api_key_encryption_backfill_v1` (`hosts.api_key`/`api_key_hash`/`api_key_enc`).
