# Web design standard

The binding design contract is now [DESIGN.md](../DESIGN.md) at the repository
root. Read it before designing, changing or reviewing any browser UI. It covers
the admin console, integrated operator chat, authentication, setup, help and
failure states, with research sources, concrete rules and acceptance checks.

This file remains only as a compatibility pointer for existing links. The old
navigation and settings-ownership tables are superseded. The new standard
distinguishes the inspected baseline from the target; adoption on 2026-10-18
does not mean the UI migration or its browser acceptance checks have run.
