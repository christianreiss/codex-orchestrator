Die Flottenkonsole

Wer arbeitet
woran?

Öffne eine Sitzung direkt aus der Host-Übersicht der aktiven Clients. Du siehst ihren Auftrag und kannst im Gespräch eine Entscheidung treffen, während der Agent auf seinem Host weiterarbeitet.

Installation

Starte deine
eigene Flotte.

Du brauchst einen Server mit Git, Docker Compose v2, curl und OpenSSL. Der Assistent richtet die Dienste ein und gibt dir nach erfolgreicher Prüfung die URL deiner Konsole.

Installationsanleitung ↗
Terminal bash
git clone https://github.com/christianreiss/codex-orchestrator.git
cd codex-orchestrator
bin/orchestrator setup

Danach registrierst du den ersten Host und weist ihm eine Engine zu.
